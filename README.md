# Inventario Dental

App web instalable para llevar el inventario de insumos de clínicas dentales: varias clínicas, mínimos por clínica, aviso de lo que está bajo el mínimo, descuento de lo usado en cada atención y listas de compra por correo, WhatsApp o PDF.

Funciona sin internet después de abrirla una vez. Los datos quedan guardados en cada dispositivo: no se envían a ningún servidor ni servicio externo.

**Abrir e instalar:** https://crisu-1993.github.io/inventario-dental/

- iPhone: abre el enlace en Safari › Compartir › Agregar a pantalla de inicio.
- Android: abre el enlace en Chrome › menú ⋮ › Instalar app.

Para actualizar la app, sube los archivos nuevos encima de los actuales (Add file › Upload files).
